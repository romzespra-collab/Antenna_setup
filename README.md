# Antenna_setup  v0.2.1

Настройка ноутбука (Windows 10/11) под антенну, подключённую кабелем / PoE.

## Что делает
- Пресеты антенн (Comfast CF-E314N, TP-Link TL-WA5210G, Ubiquiti NanoStation M5) + свои (правый клик по списку).
- Ставит статический IP на адаптер, сначала запомнив прежние настройки (IP, шлюз, DNS или DHCP).
- Проверяет антенну: пинг, порты 80/443, веб-страница. После смены IP проверяет сама, с повторами.
- Открывает веб-интерфейс (http или https — по тому, что отвечает).
- «Вернуть как было» — прежние настройки адаптера (или DHCP, если снимка нет).
- Обновление с GitHub (вкладка «Обновление»; для приватного репозитория нужен токен с правом Contents: read).

## Запуск
1. `setup.bat` — ставит Python (winget) и PySide6, запускает программу.
2. Дальше — двойной клик по `antenna_setup.pyw`. Права администратора программа попросит сама.

Клавиши: F5 — обновить адаптеры, F6 — проверить, Ctrl+Enter — поставить IP, Ctrl+O — веб,
Ctrl+S — сохранить, Ctrl+T — тема, Esc — стоп.

## Сборка в EXE
`build_exe.bat` → `dist\antenna_setup.exe`. Самопроверка: `antenna_setup.pyw --selftest`.
