# Antenna_setup  v0.6.6

Настройка ноутбука (Windows 10/11) под антенну, подключённую кабелем / PoE:
найти антенну на кабеле, поставить ноутбуку подходящий адрес, проверить связь,
открыть веб антенны и потом вернуть сеть как было.

## Запуск
1. `setup.bat` — один раз на новом компьютере: находит или ставит Python 3.15
   (с python.org), ставит PySide6 (`requirements.txt`), делает самопроверку и
   запускает программу. Окно в конце ждёт нажатия клавиши.
2. Дальше — двойной клик по `antenna_setup.pyw`. Права администратора
   программа попросит сама.

Самопроверка: `antenna_setup.pyw --selftest` (отчёт — `selftest.txt`).

## Что умеет
- **🔎 Найти антенну** — поиск в своей подсети (шлюз, DHCP-сервер), затем —
  после вопроса — в заводских подсетях (192.168.1/0/10/88/…) с временным
  адресом ноутбука .247; не нашёл — сеть возвращается.
- **👂 Найти по MAC** — прослушка кабеля через Npcap (ARP, LLDP, DHCP, MNDP и
  др.): IP и MAC антенны в любой подсети без запросов к её веб. Антенне,
  которая ждёт адрес по DHCP, программа выдаёт его сама
  (ноутбук 192.168.77.1, антенна 192.168.77.2).
- **📶 Wi-Fi антенны** — подключить ноутбук к Wi-Fi самой антенны и зайти в её
  веб, как с телефона; «Вернуть как было» возвращает домашний Wi-Fi.
- **⚡ Поставить IP** — статический адрес на выбранный адаптер; прежние
  настройки (IP, шлюз, DNS или DHCP) запоминаются.
- **✔ Проверить** — пинг, порты 80/443, веб-страница; после смены IP — сама,
  с повторами. **🌐 Открыть веб** — http или https, что отвечает.
- **📖 Прочитать настройки** — модель, прошивка, режим, адреса, SSID, сигнал
  (распространённые веб-интерфейсы антенн).
- **🛠 Настроить ПК** — интернет только через Wi-Fi, кабель — для антенн;
  домашняя сеть закрыта для поиска.
- **↩ Вернуть как было** — прежние настройки адаптера (нет снимка — DHCP),
  маршруты и Wi-Fi. Временный адрес не остаётся: при выходе и при следующем
  запуске программа предлагает вернуть сеть.
- **📤 Отправить журнал** — журнал и найденное в приватный репозиторий отчётов.
- **⏹ Стоп** — сразу остановить проверку, поиск, чтение, отправку.

Клавиши: F5 — обновить адаптеры, F6 — проверить, F7 — найти антенну,
Ctrl+Enter — поставить IP, Ctrl+O — веб, Ctrl+S — сохранить, Ctrl+T — тема,
Esc — стоп.

## Настройки
Вкладка «Настройки»: ожидание и число повторов проверки, автопроверка,
запрос прав администратора, «интернет только через Wi-Fi», логин/пароль веба
антенны (по умолчанию admin / admin), репозиторий и токен для отчётов
(«Отчёт для Claude»), тема. Всё хранится в `config.json` рядом с программой
(с копией `config.json.bak`).

## Обновление с GitHub
Вкладка «Обновление» (или ⋯ → «Обновить программу с GitHub»): проверка,
«Что нового» (из `CHANGELOG.md`), скачивание, установка поверх, перезапуск.
Общий модуль `app/gh_update*.py`. Репозиторий публичный — токен не обязателен;
как получить токен «только чтение» — кнопка «?». Обновляется только программа
на Python; собранный exe сам не обновляется.

## Сборка в EXE
`build_exe.bat` → `dist\antenna_setup.exe` (PyInstaller, `antenna_setup.spec`,
просит права администратора). Новую версию exe — собрать заново.

## Файлы
- `antenna_setup.pyw` — программа; `app/` — модуль обновления с GitHub.
- `CHANGELOG.md` — журнал изменений (последние версии; раньше — в истории git).
- `setup.bat`, `requirements.txt` — установка; `build_exe.bat`, `antenna_setup.spec` — сборка exe.
- Создаются при работе: `config.json`, `antenna_setup.log`, `selftest.txt`.
- `release/` — архив текущей версии для обновления.
