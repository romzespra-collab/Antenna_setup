# Antenna_setup  v0.3.0

Настройка ноутбука (Windows 10/11) под антенну, подключённую кабелем / PoE.

## Что делает
- «🔎 Найти антенну»: ищет на кабеле в своей подсети, потом в заводских (192.168.1/0/10/88/…):
  ставит ноутбуку временный адрес .247, ищет веб антенны (порты 80/443). Не нашёл — сеть возвращается.
- Ставит статический IP на адаптер, сначала запомнив прежние настройки (IP, шлюз, DNS или DHCP).
- Проверяет антенну: пинг, порты 80/443, веб-страница. После смены IP проверяет сама, с повторами.
- Открывает веб-интерфейс (http или https — по тому, что отвечает).
- «Вернуть как было» — прежние настройки адаптера (или DHCP, если снимка нет).
- Обновление с GitHub — общий модуль `app/gh_update.py` (как в SmartMon).

## Запуск
1. `setup.bat` — как START_ON_NEW_PC.bat в SmartMon: один Python 3.15 на компьютер (нет — ставит с python.org),
   PySide6, самопроверка, запуск. Окно в конце ждёт нажатия клавиши.
3. Дальше обновлять без флешки: вкладка «Обновление» (или ⋯ → «Обновить программу с GitHub»). Токен — тот же,
   что в SmartMon (только чтение); как получить — кнопка «?».
2. Дальше — двойной клик по `antenna_setup.pyw`. Права администратора программа попросит сама.

Клавиши: F5 — обновить адаптеры, F6 — проверить, F7 — найти антенну, Ctrl+Enter — поставить IP, Ctrl+O — веб,
Ctrl+S — сохранить, Ctrl+T — тема, Esc — стоп.

## Сборка в EXE
`build_exe.bat` → `dist\antenna_setup.exe`. Самопроверка: `antenna_setup.pyw --selftest`.
